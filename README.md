# 우리집을 지켜라!

React + TypeScript + Three.js + Vite로 만든 캐주얼 3D 타워 디펜스입니다. 슬리퍼를 신은 평범한 집주인이 살림살이를 동원해 어이없는 불청객에게서 집을 지킵니다. 외부 모델 없이 직접 만든 로우폴리 주택·상점·생활 소품과 GPU 스킨 애니메이션 캐릭터를 사용합니다. 실시간 그림자, PC 화면의 접촉 음영(SSAO), 입자와 발광 후처리를 적용합니다.

## 실행과 검증

Node.js 22.12 이상 또는 24 LTS가 필요합니다.

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

개발 서버 주소는 실행 출력에 표시됩니다. 같은 Wi-Fi의 모바일에서는 개발 PC의 LAN 주소를 사용하세요.

## 플레이

- S자 골목에 24개의 건설 부지가 있습니다. 도로 사이 세 잔디 구간의 폭을 줄이고 부지를 중앙에 배치해, 내부 18개 부지의 기본 장치가 위·아래 도로를 모두 공격할 수 있습니다.
- 주인공은 빗자루를 든 슬리퍼 집주인입니다. 좀도둑, 왕모기, 걸어 다니는 스팸 전화, 소음 스피커와 월요일 달력 보스가 등장합니다.
- 빨래집게 발사대는 빠른 공격, 택배 상자 대포는 범위 공격, 초강력 선풍기는 감속을 담당합니다. Q / 물벼락 버튼은 주변 적에게 대청소 공격을 합니다.
- PC: WASD / 방향키로 이동, Q 스킬, SPACE 다음 방문, P 일시정지, ESC 건설 패널 닫기.
- PC 왼쪽 드래그는 화면 이동입니다. 카메라 각도는 고정되며 오른쪽 드래그로 회전하지 않습니다. 휠은 커서가 가리키는 지점을 기준으로 확대·축소합니다.
- 모바일 한 손가락 드래그는 화면 이동, 두 손가락을 함께 움직이면 화면 이동, 핀치 인·아웃은 확대·축소합니다. 캐릭터는 가상 조이스틱으로 이동합니다.
- − / + 버튼은 현재 보는 중심으로 확대·축소합니다(65%~250%). 배율 버튼은 100%, 되돌리기 버튼은 화면 위치·배율을 초기화합니다. 화면 방향을 바꿔도 시점은 유지됩니다.
- 이동키와 조이스틱은 고정된 화면 방향을 따릅니다. 드래그·핀치로는 건설 지점이 선택되지 않습니다.
- 금색 원을 탭하거나 `건설·관리`를 열어 부지를 고르면 건설·강화할 수 있습니다. 관리 패널은 처음에 닫혀 있고, 상단·하단의 큰 배경 박스는 없앴습니다.
- 빈 부지는 걸어갈 수 있지만, 장치를 설치하면 캐릭터가 그 영역에 들어갈 수 없습니다. 건설 순간 겹치거나 저장에서 불러온 캐릭터도 바깥으로 보정합니다.
- 장치는 최대 5레벨, 집주인은 최대 10레벨입니다. 용돈으로 강화하거나 집을 수리하세요. 5·10·15·20번째 방문에는 보스가 옵니다. 1× / 2× 버튼으로 속도를 바꿉니다.
- Easy·Normal·Hard의 적 체력 배율은 각각 5·10·20배이며, 적 수·속도·보상은 같습니다. `src/game.ts`의 `DIFFICULTIES`에서 조절합니다.
- 진행은 2초마다 localStorage에 자동 저장됩니다. 이전 버전의 용돈·웨이브·강화 수준은 새 지도에 변환해 유지합니다. 브라우저 데이터를 지우면 저장도 지워집니다. 탭을 숨기면 자동으로 일시정지합니다.

## 구성과 배포

게임 규칙·저장 변환은 `src/game.ts`, 공유 지도는 `src/battlefield.ts`, 화면·조작은 `src/main.tsx`, 카메라 제스처는 `src/camera-controls.ts`, 지형·조명·전투 연출은 `src/world.ts`, 주택·상점·거리 소품은 `src/neighborhood.ts`, 모델·관절 애니메이션은 `src/world-models.ts`, GPU 입자는 `src/world-particles.ts`입니다.

지형은 재질별로 병합하고 캐릭터는 스킨 메시로 묶으며, 전투 입자는 고정 GPU 버퍼를 재사용합니다. 모바일 렌더링 해상도를 제한합니다. 외부 리소스는 선택적 Google Fonts뿐이고 연결이 안 되면 시스템 폰트를 사용합니다. WebGL을 지원하는 최신 브라우저가 필요합니다.

Vercel 설정: Framework **Vite**, Build **npm run build**, Output **dist**. 저장소의 `vercel.json`에도 설정되어 있습니다. 별도 입장 코드 없이 배포 주소로 플레이할 수 있습니다.

## 그래픽 방향

POLYGON Town의 주택·사람형 캐릭터 분위기와 Littlest Tokyo의 촘촘한 생활 배경을 참고한 자체 제작 지오메트리입니다. 원본 유료 에셋은 포함하지 않습니다. 지붕 기와선, 창틀·덧문, 발코니, 실외기, 상점 차양·한글 간판, 가로수, 주차 차량과 전선을 추가했습니다. 적 경로와 24개 건설 부지는 유지합니다.
