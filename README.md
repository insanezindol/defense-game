# Emberhold · 작은 왕국의 수호자

React + TypeScript + Three.js + Vite로 만든 싱글 플레이 타워 디펜스. 원근 카메라와 직접 제작한 3D 지형·성채, GPU 스킨 애니메이션 캐릭터, 실시간 그림자와 발광 후처리를 사용합니다. 킹샷의 캐릭터, 로고, 사운드, 소스나 아트 파일을 사용하지 않습니다.

## 실행

Node.js 22.12 이상 또는 24 LTS를 사용하세요.

```sh
npm ci
npm run dev
```

입장 코드 없이 바로 게임에 접속할 수 있습니다. 주소는 Vite 실행 출력에 표시됩니다. 같은 Wi-Fi에서 모바일로 개발 PC의 LAN 주소에 접속할 수 있습니다. Windows 방화벽에서 개발 서버 접속을 허용해야 할 수 있습니다.

```sh
npm test
npm run build
npm run preview
```

## 플레이

- 처음 시작하거나 새 게임/다시 도전하기를 선택하면 Easy·Normal·Hard를 고를 수 있습니다. 최초 기본 체력 대비 Easy는 2배, Normal은 3배, Hard는 4배입니다. 보스를 포함한 모든 적에 적용되며 적 수·속도·보상은 동일합니다. 선택 화면에는 배율 없이 난이도 이름만 표시합니다. 선택한 난이도는 저장되고 이전 저장 데이터는 Easy로 이어집니다.
- 난이도 조절: `src/game.ts`의 `DIFFICULTIES`에서 각 `enemyHpMultiplier` 상수를 수정하세요(기본 선택은 `DEFAULT_DIFFICULTY`). 변경한 배율은 새로 생성되는 적부터 적용됩니다. 체력 배율이 실제 승률이나 체감 난이도와 정확히 비례하는 것은 아닙니다.
- PC: WASD / 방향키 이동, Q 서리 폭풍, SPACE 다음 공세, P 일시정지, ESC 건설 패널 닫기.
- 모바일: 왼쪽 가상 조이스틱으로 이동, 오른쪽 번개 버튼으로 스킬 사용.
- 캐릭터는 사거리 안의 적을 자동 공격합니다. 금색 건설 부지를 클릭/터치하면 건설·강화 패널이 열립니다.
- 궁수탑은 빠른 공격, 대포탑은 범위 공격, 서리탑은 감속을 담당합니다. 건물 최대 5레벨, 영웅 최대 10레벨.
- 적 처치 보상과 공세 완료 보상으로 건물·영웅을 강화하고 성문을 수리합니다. 5·10·15·20공세에 보스가 등장합니다.
- 전장 오른쪽 아래 1× / 2× 버튼으로 속도를 전환합니다. 소리는 상단 버튼으로 켤 수 있습니다.
- 진행은 2초마다 브라우저 localStorage에 저장되며 건설/강화와 탭을 떠날 때도 저장합니다. 기기·브라우저 사이에서 공유되지 않습니다. 브라우저 데이터를 지우면 저장도 삭제됩니다.
- 탭을 숨기면 자동으로 일시정지합니다. 새 게임은 확인 후 시작합니다.

## Vercel

GitHub **private** 저장소를 Vercel에 가져온 뒤 Framework: Vite, Build: `npm run build`, Output: `dist`로 설정합니다. `vercel.json`에 동일한 설정이 있습니다.

입장 코드나 인증 환경 변수 없이 바로 플레이할 수 있습니다. 배포 주소를 아는 사람은 누구나 게임에 접속할 수 있으며, GitHub 저장소는 private으로 유지합니다.

게임 규칙: `src/game.ts`. 화면·조작: `src/main.tsx`. 전장·조명·전투 연출: `src/world.ts`. 캐릭터 모델·관절 애니메이션·카메라: `src/world-models.ts`. GPU 입자: `src/world-particles.ts`.

3D 그래픽은 금속 갑옷·방패·무기·망토를 갖춘 영웅과 네 종류 적, 회전하는 포탑과 떠 있는 서리 수정, 석재 포장·풀·절벽·산맥·횃불로 구성됩니다. 포탄은 포물선으로 비행하고, 피격·폭발·연기·서리 파편·충격파를 표시합니다. 지형은 재질별로 병합하고 캐릭터는 최대 세 개의 스킨 메시로 묶으며, 전투 입자는 고정 GPU 버퍼를 재사용합니다. 모바일에서는 렌더링 해상도를 제한합니다. 일시정지 시 전투 효과도 멈춥니다.

외부 리소스는 선택적 Google Fonts 폰트뿐이며, 연결이 안 되면 시스템 폰트를 사용합니다. WebGL을 지원하는 최신 데스크톱/모바일 브라우저가 필요합니다.
