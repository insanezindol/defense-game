# Bundled models

Selected models are authored by Kenney and distributed under CC0. The original license files are retained next to each pack.

- `residents/`: [Mini Characters](https://kenney.nl/assets/mini-characters), character-male-a and character-male-d, with authored skeletal animations and palette atlas.
- `houses/`: [City Kit (Suburban)](https://kenney.nl/assets/city-kit-suburban), building-type-b, building-type-e and building-type-k, with palette atlas.

These files ship with the game and do not require an external model server at runtime. No paid Synty assets are included.
