# 우리집을 지켜라! 구현 계획

승인된 설계: 생활 밀착형 코미디 3D 디펜스, 투명한 소형 HUD, 24개 건설 부지와 긴 S자 골목, 도로를 따르는 적, 드래그 이동·회전·지점 중심 줌.

제약: 기존 저장 진행을 변환해 유지한다. 새 라이브러리나 외부 모델 없이 Three.js를 재사용한다. 검증 후 요청된 main 커밋·푸시와 기존 Vercel 프로젝트 운영 배포를 진행한다.

- [x] 공유 지형 좌표 `src/battlefield.ts`: S자 도로, 누적 거리 보간, 24개 부지, 지도 경계. 도로 길이·부지 접근성·중복 검증.
- [x] `src/game.ts`: 도로 진행 거리 기반 생성·이동·공격 우선순위·현관 도착, 이전 저장 변환, 생활용품 명칭. 기존 규칙과 새 경로 검증.
- [x] `src/camera-controls.ts`: 팬·회전·기준점 줌·초기화·화면 기준 입력. 수학 단위 검사와 브라우저 마우스·터치 검증.
- [x] `src/world-models.ts`: 주민·좀도둑·왕모기·소음 스피커·월요일 및 생활용품 방어 장치. 기존 스킨·자원 해제 재사용.
- [x] `src/world.ts`: 밝은 주택가, 공유 좌표를 이용한 도로와 24개 부지, 우리집·생활 소품, 카메라와 새 모델 통합.
- [x] `src/main.tsx`, `src/style.css`, `index.html`: 이름·문구·최소 HUD·접이식 건설 패널, 모든 화면 크기의 조작 유지.
- [x] 전체 테스트·빌드·브라우저 게임 플레이 및 저장 호환성 검증. 독립 검토 후 수정, README와 미리보기 갱신.

검토 중점: 도로 밖 적 이동, 지름길/조기 현관 피해, 사거리 밖 부지, 저장 진행 손실, 드래그/핀치 후 오선택, 회전 후 이동 방향, 모바일 HUD 겹침.

검증 결과: 자동 테스트 30개, TypeScript/Vite 빌드 통과. 브라우저에서 커서 줌 기준점 오차 1.8e-15, 좌우 드래그 팬·회전, CDP 두 손가락 회전·1.5배 핀치, 부지 탭 및 드래그/핀치 오선택 방지 확인. 320/390 세로, 844 가로, 768 태블릿 화면에서 오버플로 없이 표시. 실제 UI 건설→강화→웨이브→새로고침 저장 유지 확인. 최종 배포용 빌드를 미리보기 서버에서 실행해 런타임 오류 없음. 별도 검토에서 발견한 앞쪽 지도 경계 충돌은 회귀 테스트로 수정, 캐릭터 발광 재질 오분류도 수정·검증. README와 gameplay.png 갱신.

범위: 로컬 구현·검증까지. 실제 모바일 기기 성능과 모든 난이도의 장기 플레이 밸런스는 측정하지 않음. 후속 승인 범위에 main 커밋·푸시와 Vercel 운영 배포를 포함한다.
